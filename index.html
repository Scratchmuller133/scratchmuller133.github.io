📋 About the Project

Smart Safety Network provides a reliable way to monitor location and request help during emergencies. The application runs through your web browser and combines GPS data with voice controls to ensure quick access to assistance when you need it most.

🚀 Core Features

  • SOS Alerts: Send instant notifications to contacts.
  • GPS Tracking: View precise location data in real time.
  • Google Maps Integration: Navigate to safety with reliable mapping tools.
  • Voice Assistance: Control the interface using simple voice commands.
  • Multilingual Support: Change the language settings to match your needs.

💻 System Requirements

Before you begin, ensure your computer meets these basic requirements to run the software smoothly:

  • Operating System: Windows 10 or Windows 11.
  • Browser: Google Chrome, Microsoft Edge, or Mozilla Firefox.
  • Internet Connection: Active connection for real-time tracking and maps.
  • Permissions: Enabled microphone and location services in your browser settings.

📥 Download and Setup

Follow these steps to access the application on your computer:

  1. Visit the project repository page to view the latest software release.
  2. Look for the section marked Releases on the right side of the page.
  3. Click the most recent version tag.
  4. Download the compressed folder or the installer file for Windows.
  5. Extract the files to a folder you can easily access on your desktop.
  6. Run the executable file or open the main index file in your web browser.

⚙️ Using the Application

Once you open the software, the interface displays a dashboard. You must grant the website permission to see your location and listen to your microphone. These permissions allow the GPS and voice assistant features to function correctly.

To set up an SOS alert, click the settings icon in the top right corner. Enter the phone numbers or email addresses of the people you want to alert during an emergency. Test the connection at least once to ensure your contacts receive the messages.

❓ Frequently Asked Questions

Does the app track me when it is closed? No. The application only shares your location while the browser tab remains active and you have granted permission.

Can I use this without the internet? Most features require an internet connection to send alerts and load map data.

How do I change the language? Select the language menu button on the main dashboard to switch between available languages.
